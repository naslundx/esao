# esao

Theme originally based on INFINITY from http://www.Styleshout.com

## Development

This project uses ESLint and Stylelint to maintain code quality.

### Linting

To run the linters, ensure you have Node.js installed, then run:

```bash
npm install
npm run lint
```

The project is configured to:
- Check JavaScript files in `js/` (excluding vendor libraries).
- Check CSS files in `css/` (excluding vendor stylesheets).
